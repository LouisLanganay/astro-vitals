Astro Vitals for Android. NASA Space Apps 2026, team Coflop.

The app is a daily health self-check for one astronaut on a Mars transit. The Rust core runs on the phone. All data stays on the device.

## Install

1. Download `astro-vitals-1.0.0.apk` below on an Android phone (Android 7 or later, 64-bit ARM).
2. Open the file. If Android asks, allow the install from this source.
3. Open Astro Vitals. The first start loads the `sleep_debt` demo mission.

The APK is not from the Play Store. It has a debug signature.

Web demo: https://louislanganay.github.io/astro-vitals/

Prototype, not a medical device.
